The sheet every screen copies from. Same format note as Flow: this is a 1400×2000 reference document, so the live panel shows the contested components at full fidelity in both themes rather than duplicating the whole board twice.

The board that defines the system is the biggest remaining leak

Components paints #3A5CCC thirty-one times. It carries 34 references to --accent / --accentfill / --bartrack and no data-field at all, so every one of them falls through to the base default — the reflective ink. That is the undeclared blue you first spotted on Onboarding, and it is now most concentrated on the sheet whose entire job is to be the reference.

To be precise about which uses are wrong, because most are not: I swept all 22 boards. On Field, Flow, Genesis, Main, NowPlaying, Pulse, Receipt and You, --accent resolves to the fused quadrant — that is the quadrant system working exactly as designed. The leak is only on boards with no field, and there are seven: Components (34), Tokens (10), the four State boards (10 between them), Plan (3), and Consent (1, which you deliberately kept). Components and Tokens are two thirds of it.

Four things the sheet is missing or out of step on

It still hand-draws the Spotify mark. One fill="var(--spotify)" path, and zero occurrences of the official-asset slot. Across Sign in, Now Playing and the Mix receipt the convention is now represented, not reproduced — a dashed slot standing for the official PNG, because redrawing the mark is not permitted and SpotifyAttribution.tsx already ships the correct asset. The sheet that defines the convention does not follow it.

There is no Switch and no Slider. Both exist on Profile now — a 52×44 brand switch and a brand slider with its track. They appear on this board only as illustrations inside the two system rules, which is the wrong place: a rule shows why, a component entry shows the states. Neither has a documented rest / pressed / disabled matrix, and the switch has no OFF state drawn anywhere.

There is no accordion. Connect uses two (“Why connect music?”, “Why we ask for health data”) and Consent uses eight collapsible sections. That is ten instances of one pattern across two screens, with no entry on the sheet, so its open state, its chevron rotation and its body treatment are defined nowhere.

The destructive example predates the token. The board draws “Delete my account” with var(--danger) ×4. Since screen 13 there is a declared --destructive, seeded from the same red but named separately so error and destruction can diverge. The board and the source now disagree — and this is the one sheet where showing both side by side would make the distinction legible instead of leaving it as a comment in VaultConsentPanel.tsx.

What is right

Nine component entries, each with a state row and a rule line: Button, the four bar grammars, Row, Chip, Placement, Honest empty, State read, Mini player, Tab item. The bar-grammar entry is the strongest thing on the board — it names four meanings (a ceiling is an exclusion, a target is a point, a bias is a signed nudge, a stack is a composition) that the canvas had been drawing as one left-anchored fill. The two system rules you ratified last turn are in place and marked revisitable.
