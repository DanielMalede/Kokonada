### The evidence: the spike (lane LA, 2026-11-23, on `chore/rn-upgrade`)

- The set above, installed with `npm ci` in the task worktree. The full mobile jest suite runs 233 suites and 3455 tests, and every test passes except the QA-043 tsc ratchet: React Native 0.87's Strict TypeScript API raises it from 14 to 38 diagnostics, all type-only. #308 re-records the baseline, and `OPS-495` tracks the fixes.
- Android (JDK 17, Gradle 9.4.1, AGP 9.2.1): CI's two compile steps build, and the full release native build for arm64-v8a links every library: Skia 2.6.9, screens 4.30.1, Reanimated, worklets, gesture-handler, MMKV and safe-area-context. `play-services-auth` stays 21.4.0.
- The merged manifests: release and the lab are identical to 0.86's. Debug and debugOptimized gained `ACCESS_LOCAL_NETWORK` from react-android's debug library, and #308 removes it.
- Against 0.87.1: the debug permission, the narrowed package exports and the Strict TypeScript API all arrive in 0.87.0, so the fallback avoids none of them. 0.88.1 carries the Android right-to-left fix that reads the active locale (`e46189e1e1`, `UI-055`), and 0.87.1 does not. 0.87 also leaves active support when 0.89 ships (about 2026-12-07).
- Not proven by the spike: iOS (frozen), and the runtime on a device or emulator. #308 records what its emulator run shows.
