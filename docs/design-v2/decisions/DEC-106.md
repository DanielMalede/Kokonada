- HIG basis (Apple HIG, "Sign in with Apple", "Using the system-provided buttons", "White with outline"; read 2026-09-30): "Use this style on white or light-color backgrounds that don't provide sufficient contrast with the white button fill. Avoid using this style on a dark or saturated background, because the black outline can add visual clutter; instead, use the white style to contrast with a dark background." The light canvas is `surface.base` `#FAFAFF` (`tokens.ts:170`), about 1.04:1 against the white fill, so the condition holds. The dark face uses White.
