### Ruling 3b, Fork 1 · lines 226–232

> **3b, Fork 1 (runtime statics). ACKNOWLEDGED, with four amendments.**
> 1. **Add `field.graph.nodes` to the allow-list.** This is the J/C/R/I/R0 → anchor and rest-glow map. Add a pin, G10: `fieldFrame.ts:92`'s QUADRANT map and the R0 rest-glow binding equal it. A swapped quadrant would recolour the circumplex.
> 2. **Correct G4.** Linen's rest lobes sit at 1.12R, so "inside the unit disc" would reject valid tokens. The rule becomes: lobes are finite, there are 1 or 2, and |c| ≤ centreAlpha + centreBeta of the same direction (plus 1e-9).
> 3. **Prose and capture data stay in EXTENSIONS.** Prose stays there (`rule`, `selection`, `nodeColour`, `waypoint`, `lobeOffset`, `warp`, `shimmer`, `still`, `breathPhase`), and runtime code never reads it. The capture and test data also stays: `hero`, `hardest`, `neverRedScenes`, `opaqueSurfaces`, `neverRed.rule`, and the `edgeInk` lists.
> 4. **The allow-list literal carries the designer lock.** Adding or removing a key needs my sign-off, recorded beside the literal. The haptic fallbacks join at F8 with that sign-off.
>
> The classification moves no source value, so the locks and hashes of the source files are unchanged.
