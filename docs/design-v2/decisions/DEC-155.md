## The reading

- `CLAUDE.md` binds every session, sub-agent and cloud session, and Codex through `AGENTS.md`; any other file that conflicts with it is a defect to fix.
- A session merges its own PR when every approver the jurisdiction table in `CLAUDE.md` requires has approved at a SHA still valid at the head, `merge-guard` is GREEN and `coord check --merge` passes. Nobody approves their own work, and the session that wrote the code never counts as a reviewer.

- Under DEC-142 the orchestrator still rules design gates (G2, G3, G6), the V1 direction and pin reversals with the agents' recorded consensus; it no longer rules a DEC- entry that touches law, privacy, consent or counsel.
- A `security-auditor` BLOCK is terminal: a fix and a re-review, or the owner's own acceptance of the named risk.
- Page G13 is the merge rule.
