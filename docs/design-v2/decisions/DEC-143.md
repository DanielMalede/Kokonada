### How the orchestrator applies it (the excerpt's reading, verbatim)

- Merges: by the orchestrator, only after every gate passes; after each merge a dedicated post-merge verification agent checks CI green on main and content equality, and anything left unfixed is fixed before the next task. Never a push to main, never force.
- Production writes: only those written in an approved plan, only after the full record and a resilience PASS; never outside a plan.
- Steps needing the hotspot or the phone wait; everything else continues; the owner is notified by push notification and a chat line.
