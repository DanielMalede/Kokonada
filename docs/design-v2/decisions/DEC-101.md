### HX_PLAN.md · §2 (DT-9) · line 280

- **DT-9:** a new DEC. For a fix with no device path, "verified" means a device action where one exists, plus a production database or log read, or integration tests plus a production count of zero affected users. The PR says which parts were driven on the device.
