## The scribe's notes

- **What it settles.**
  - Every session and every sub-agent runs on Fable. Ruling 2 replaces the half of ruling 1 that kept the agents on the earlier model.
  - Every sub-agent runs at effort medium (rulings 1 and 3). No dispatch prompt and no command file carries the keyword that asks for maximum depth (ruling 1).
  - Every agent file under `.claude/agents/` says `model: inherit` and `effort: medium` (ruling 5), so a sub-agent runs on the model the owner set for the session, and no dispatch names a model.
  - `CLAUDE.md` § Models says so in one paragraph, and `docs/ORCHESTRATOR_FABLE.md` `<model_economy>` points to it (DEC-155 ruling 2).
  - DEC-155's "No model version numbers anywhere in the layer." stands unchanged: `CLAUDE.md`, the agent files and the command files name no version, and a test pins it.
- **Why the files inherit** (the orchestrating session's findings of 2026-11-26 and 2026-11-27, not the owner's words).
  - A dispatch can name a model family only, never a version. In every sub-agent transcript of those two days a dispatch that named the family ran on a version the dispatch did not choose: 5.2, where ruling 3 names 5.1.
  - A dispatch that names no model falls to the agent file's `model:` line, which named the earlier family.
  - With `model: inherit` the sub-agent runs on the session's model, which the owner sets himself.
- **What it does not settle.**
  - The version. It is whatever the owner sets for the session with /model, and it is not recorded in the layer. Rulings 1 and 3 name versions in his own words; this entry quotes them as the record and writes neither into `CLAUDE.md`, an agent file or a command file.
  - The session's own effort. Ruling 3 says he moves the session himself; the layer sets the sub-agents' effort only.
  - `scripts/run-mission.ps1`, the Wave-4 runner, which still names models and opens its prompt with the keyword. It starts sessions of its own and dispatches no sub-agent, it refuses nothing today (`OPS-109`) and it is listed for removal (`OPS-279`); `OPS-556` carries it.
  - Codex. `AGENTS.md` marks the models and the `effort` lines "Not applicable", and this entry changes nothing there.
- **The record of ruling 1** is second-hand: the session's memory note of 2026-10-27 quotes the message, and the note is outside the repo. Rulings 2 to 5 reached the scribe through the orchestrating session's brief. No verbatim excerpt of the question behind ruling 5 is filed yet (`OPS-557`).
