### CMP-002 · Spotify content always carries the Spotify brand
- kind: OBLIGATION
- rule: Every view that shows Spotify metadata (track, artist, album or playlist name) or cover art, or plays Spotify audio, shows the Spotify logo on that same view.
- source: Spotify Design Guidelines, "Attribution": "If you use any Spotify metadata (including artist, album and track names, album artwork, and audio playback) it must always be accompanied by the Spotify brand." Spotify Developer Policy II.4.1: "If you display any Spotify Content you must clearly attribute the content as being supplied and made available by Spotify, by using the Spotify Marks." https://developer.spotify.com/documentation/design ; https://developer.spotify.com/policy · retrieved 2026-09-29
- provider: Spotify
- applies to: P1 (mini-player, if any), P3, P4, P8, F10
- surfaces: Now Playing, Up Next rows, Receipt items, History rows, `mobile/KokonadaHealth/src/experience/player/SpotifyAttribution.tsx`, AttributionSlot
- verify at: CI — an RNTL test shows the mark renders whenever an item from Spotify renders. G12 — captures of every state that has Spotify metadata.
- severity if broken: P0
- depends on: CMP-003, CMP-126
- status: SETTLED
- re-verify by: 2026-11-28
