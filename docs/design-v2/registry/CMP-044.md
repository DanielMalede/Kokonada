### CMP-044 · Honour revocations made on Google's side
- kind: OBLIGATION
- rule: The backend checks from time to time that its YouTube tokens still work. When a token cannot be refreshed, it deletes all of that user's YouTube data within 30 days.
- source: YouTube API Developer Policies III.D.2, item 3.2: "your API Clients will need to periodically reconfirm that its authorization tokens are still valid and delete API Data associated with users whose authorization tokens cannot be refreshed … must take place within 30 calendar days of that revocation." · retrieved 2026-09-29
- provider: YouTube
- applies to: backend, P9
- surfaces: `backend/app/workers/youtubeRetention.worker.js` purges when a refresh fails for good. It must reach `UnclassifiedTrack` and `PlaylistSession` too (BE-034).
- verify at: CI — a worker test covers every collection derived from YouTube
- severity if broken: P0
- depends on: CMP-045
- status: SETTLED
- re-verify by: 2026-11-28
