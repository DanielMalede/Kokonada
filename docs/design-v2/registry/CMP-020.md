### CMP-020 · No Spotify content goes to third parties
- kind: PROHIBITION
- rule: No Spotify track ID or metadata is sent to any third-party service, including feature APIs, the LLM provider and diagnostics.
- source: Spotify Developer Policy III.9: "Do not build an SDA that enables the transfer of data to another service, except for the purpose of enabling a user to transfer their personal data, or the metadata of the user's playlists to another service." https://developer.spotify.com/policy · retrieved 2026-09-29
- provider: Spotify
- applies to: backend, server plumbing
- surfaces: `featureService.js:26-40` drops Spotify rows before the measured fetch. `docs/plans/HALT_SPOTIFY_TRACK_IDS_TO_THIRD_PARTY.md` is still open, and nobody has checked the outbound leak-monitor guard (TASKS BE-043; that re-audit is owed before P3's G5).
