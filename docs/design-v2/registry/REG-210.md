### REG-210 · UK: evidence on file for objective health claims
- kind: OBLIGATION
- rule: Every objective claim related to health in UK marketing (the listing, the website, ads) has documentary evidence on file before it is published. No copy discourages anyone from seeking medical care.
- source:
  - CAP Code 12.1: "Objective claims must be backed by evidence, if relevant consisting of trials conducted on people".
  - CAP Code 12.2: "Marketers must not discourage essential treatment for conditions for which medical supervision should be sought".
  - https://www.asa.org.uk/type/non_broadcast/code_section/12.html. retrieved 2026-09-29 [RETRIEVED; a self-regulatory code, and its reach over an app-store listing was not confirmed]
- jurisdiction: UK
- classification assumption: holds on every branch.
- applies to: P13, store listing
- surfaces: the listing and any website
- verify at: store submission
- severity if broken: P0
- depends on: REG-208
