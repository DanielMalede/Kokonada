### CMP-059 · Data that is not Garmin's is never labelled Garmin
- kind: PROHIBITION
- rule: Heart rate from a Bluetooth strap and Health Connect data from other apps are never stored, shown or exported as Garmin. User copy names Garmin only for a user whose data really came from Garmin.
- source: Garmin Developer API Brand Guidelines V 6.30.2025: an attribution "must not imply Garmin endorsement of data from other devices" (txt:75-76). Agreement §5.2(g), as in CMP-058. · retrieved 2026-09-29
- provider: Garmin
- applies to: backend, P6, P7, P9
- surfaces: `backend/app/controllers/integrationsController.js:712` (token mint sets `wearableProvider='garmin'`) and `:811` (Bluetooth reading tagged `'garmin'`), BE-030 and BE-031; `ProfileScreen.tsx:155` tells every Health Connect user to "Open Garmin Connect → Settings → Health Connect" (MB-058)
- verify at: CI — source-enum tests. G12.
