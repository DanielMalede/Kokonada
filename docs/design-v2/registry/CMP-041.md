### CMP-041 · Items from YouTube carry YouTube attribution
- kind: OBLIGATION
- rule: Any item whose content comes from YouTube API data shows the official YouTube brand features, and any YouTube logo links to YouTube content. Items that did not come from YouTube never carry YouTube marks. This requires a provider marker on every track in the payload.
- source: YouTube API Developer Policies III.F.2.a (as in CMP-038) and III.F.2.c (never "interfere with or obscure any attribution provided by YouTube"). YouTube Branding Guidelines: "Any YouTube logo used within an application must link back to YouTube content or to a YouTube component of that application." · retrieved 2026-09-29
- provider: YouTube
- applies to: P3, P4, P8, server plumbing, F10
- surfaces: `playlist_ready` tracks have no provider discriminator (UI-003 YT-2); Receipt lines that cite YouTube likes; History rows
- verify at: CI — a DTO test shows every track carries a provider. G12 — captures.
- severity if broken: P0
- depends on: CMP-126
- status: SETTLED
- re-verify by: 2026-11-28
