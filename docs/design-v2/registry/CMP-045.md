### CMP-045 · YouTube data is kept for 30 days at most
- kind: PROHIBITION
- rule: YouTube data the user authorised (liked videos, titles, channels, and taste derived from them) is kept for 30 calendar days at most, then deleted or refreshed.
- source: YouTube API Developer Policies III.E.4.c: "API Clients may store all other types of Authorized Data … for no longer than 30 calendar days". https://developers.google.com/youtube/terms/developer-policies · retrieved 2026-09-29
- provider: YouTube
- applies to: backend, P8, server plumbing
- surfaces: `PlaylistSession.trackSummary` for tracks from YouTube (no TTL); `backend/app/models/UnclassifiedTrack.js:7-20` (no expiry, BE-034); the YouTube-derived fields `topArtists` and `topGenres`
- verify at: CI — TTL tests
- severity if broken: P0
- depends on: CMP-024
- status: HALT
- re-verify by: 2026-11-28
