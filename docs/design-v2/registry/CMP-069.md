### CMP-069 · Show the source app for Health Connect data
- kind: OBLIGATION
- rule: Every value read from Health Connect shows the name of the app that supplied it (and its icon where possible), taken from `DataOrigin.packageName`. Values the server computes carry that origin in their DTO.
- source: Health Connect "Data display and attribution": the app "must display the app source icon and name (or only the app name if the icon can't be shown) for data read from Health Connect". https://developer.android.com/health-and-fitness/health-connect/ui/data (updated 2026-09-22) · retrieved 2026-09-29
- provider: Health Connect
- applies to: P7, P4, server plumbing
- surfaces: nothing in `src` uses `dataOrigin` (MB-035); the Pulse DTO
- verify at: CI — a DTO test. G12 — capture.
- severity if broken: P1
- depends on: none
- status: SETTLED
