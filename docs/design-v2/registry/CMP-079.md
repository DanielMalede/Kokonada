### CMP-079 · Permissions only in context, only for current features
- kind: OBLIGATION
- rule: The app requests OS permissions only when the user invokes the feature, only for features the listing promotes, never at launch and never in onboarding.
- source: Google Play "Permissions and APIs that Access Sensitive Information": "Request permissions and APIs that access sensitive information to access data in context (via incremental requests)…"; "You may only request permissions … that are necessary to implement current features or services in your app that are promoted in your Google Play listing." https://support.google.com/googleplay/android-developer/answer/9888170 · retrieved 2026-09-29
- provider: Google Play
- applies to: P1, P2, P6, P10, Q3
- surfaces: bootstrap and onboarding make no permission call
- verify at: CI — tests. G12 — a first-run recording shows no OS dialog.
- severity if broken: P0
- depends on: none
- status: SETTLED
- re-verify by: 2026-11-28
