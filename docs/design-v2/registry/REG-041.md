### REG-041 · No repeated prompting after a refusal
- kind: PROHIBITION
- rule: After a Decline, the health request does not come back on its own. It returns only when the user acts (for example, taps Connect) or when the consent version changes.
- source: GDPR Recital 32 ("…the request must be clear, concise and not unnecessarily disruptive to the use of the service for which it is provided.") [K5] · retrieved 2026-09-29 (RETRIEVED).
