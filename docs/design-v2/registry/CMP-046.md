### CMP-046 · YouTube data is never given to other services
- kind: PROHIBITION
- rule: A user's YouTube data is neither shown to nor passed to anyone other than that user, unless the user has expressly approved it after a disclosure that names the recipient.
- source: YouTube API Developer Policies III.E.3.b: "API Clients must not display or allow access to Authorized Data to anyone other than the authorizing user or agents expressly approved by that user". https://developers.google.com/youtube/terms/developer-policies · retrieved 2026-09-29
- provider: YouTube
- applies to: backend, P6
- surfaces: `backend/app/services/crossPlatform.js:57-95` (YouTube titles and channel names go to Spotify search); YouTube artist names go to the LLM provider when the profile is built (`musicProfileService.js:654-662`, TASKS BE-035)
- verify at: CI — egress tests. G1 — the P6 brief.
- severity if broken: P0
