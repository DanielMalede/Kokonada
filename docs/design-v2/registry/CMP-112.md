### CMP-112 · Large screens ignore orientation locks
- kind: OBLIGATION
- rule: Every page defines its large-screen layout, because the phone's portrait lock does not apply when the smallest width is 600 dp or more. The temporary opt-out is not relied on.
- source: Android 16 behaviour changes: "For apps targeting Android 16 (API level 36), orientation, resizability, and aspect ratio restrictions no longer apply on displays with smallest width >= 600dp"; the opt-out "is temporary and won't apply when targeting API level 37". · retrieved 2026-09-29
- provider: Android
- applies to: F5, P1–P11
- surfaces: `screenOrientation` in the manifest and navigation
- verify at: G11 — a capture on a large-screen profile
- severity if broken: P1
- depends on: CMP-011
- status: SETTLED
- re-verify by: 2026-11-28
