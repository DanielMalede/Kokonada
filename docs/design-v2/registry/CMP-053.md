### CMP-053 · "Garmin [device model]" on every primary Garmin view
- kind: OBLIGATION
- rule: Every dashboard, card or summary that shows Garmin API data carries "Garmin [device model]". Bare "Garmin" is allowed only when the API gives no model, and the literal "[DEVICE MODEL]" never appears.
- source: Garmin Developer API Brand Guidelines V 6.30.2025, "TITLE-LEVEL OR PRIMARY DISPLAYS": "All uses of Garmin device-sourced data within dashboards, activity feeds, overview cards or summary views must include a 'Garmin [device model]' attribution… If the device model is not provided or unknown via the API, list Garmin as the data source." (txt:30-32). https://developer.garmin.com/downloads/brand/Garmin-Developer-API-Brand-Guidelines.pdf · retrieved 2026-09-29
- provider: Garmin
- applies to: P7, P2 (source chip), F10
- surfaces: the Pulse hero and chips; `warmStore` source has no `'garmin'` value
- verify at: G12 — a capture with a Garmin fixture
- severity if broken: P0
- depends on: CMP-051
