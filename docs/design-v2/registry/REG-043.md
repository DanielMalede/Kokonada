### REG-043 · Child-readable wording if children can use the app
- kind: OBLIGATION
- rule: If the minimum age lets children in, notices and consent aimed at them use "such clear and plain language that the child can easily understand".
- source: GDPR Recital 58 [K5] · retrieved 2026-09-29 (RETRIEVED). Art. 12(1) ("…in particular for any information addressed specifically to a child") [K6] · retrieved 2026-09-29 (REPRODUCTION)
- jurisdiction: EU
- classification assumption: only if the minimum age admits children
- applies to: P5, P10, P11; Stage 0 F7
- surfaces: notice and consent copy
- verify at: G5
- severity if broken: P1
