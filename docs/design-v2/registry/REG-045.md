### REG-045 · Retention stated per category, and true of the code
- kind: OBLIGATION
- rule: Each category states its retention period, or the criteria for it, and each statement is true of the code. The ones to check first:
  - session heart rate kept 30 days (BE-016);
  - band history with no TTL (BE-026);
  - `MedicalProfile` with no limit at all (BE-027).
  - The new step-14 events get a period before they ship.
- source: GDPR Art. 13(2)(a); Art. 5(1)(e) ("…no longer than is necessary…") [K6] · retrieved 2026-09-29 (REPRODUCTION). Recital 39 ("…limited to a strict minimum.") [K5] · retrieved 2026-09-29 (RETRIEVED)
- jurisdiction: EU
- classification assumption: every option
- applies to: P3, P5, P8, P9, P14; privacy notice; backend; Stage 0 step 14
- surfaces: the retention section and table
- verify at: G1 — the retention table is checked against the code's TTLs and erasure paths
- severity if broken: P0
