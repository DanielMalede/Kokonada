### CMP-117 · Ship each font's copyright notice and OFL text
- kind: OBLIGATION
- rule: For every bundled font family, the app ships its copyright line and the full OFL 1.1 text, in a licence file named for that family. The P14 licences screen shows them.
- source: SIL OFL 1.1, condition 2: fonts "may be bundled, redistributed and/or sold with any software, provided that each copy contains the above copyright notice and this license… as long as those fields can be easily viewed by the user." https://openfontlicense.org/open-font-license-official-text/. OFL FAQ: "At a minimum you must include the copyright statement, the license notice and the license text." https://openfontlicense.org/ofl-faq/ · retrieved 2026-09-29
- provider: OFL font
- applies to: F6, P14, Q1
- surfaces: `mobile/KokonadaHealth/assets/fonts/`; P14
- verify at: CI — every bundled font has its matching licence file. G12 — the P14 capture.
