### CMP-047 · Ask YouTube only for the scopes in use
- kind: OBLIGATION
- rule: The app requests `youtube.readonly` only, and only at the moment the user connects YouTube.
- source: YouTube API Developer Policies III.D.2.1.2 ("only request access to authorization scopes that they currently use"). Google OAuth 2.0 Policies: "You must only request the smallest set of scopes that are necessary for providing functionality knowingly chosen by the user." https://developers.google.com/identity/protocols/oauth2/policies · retrieved 2026-09-29
- provider: YouTube, Google OAuth
- applies to: P6, backend
- surfaces: the scope list in `backend/app/services/youtube.js`
- verify at: CI — a test on the scope constant
- severity if broken: P1
