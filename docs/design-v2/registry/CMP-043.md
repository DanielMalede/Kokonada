### CMP-043 · Disconnecting YouTube in the app revokes access at Google
- kind: OBLIGATION
- rule: When the user disconnects YouTube in Kokonada, the backend revokes the token with Google straight away, and all YouTube data it collected is deleted within 7 calendar days.
- source: YouTube API Developer Policies III.D.2, item 3.1: "When a user revokes consent through this mechanism, the API Client must programmatically revoke that token right away to communicate the change in permissions to Google… That deletion should happen as soon as possible and must take place within 7 calendar days of the revocation." https://developers.google.com/youtube/terms/developer-policies · retrieved 2026-09-29
- provider: YouTube
- applies to: P9, backend
- surfaces: the YouTube disconnect handler in `backend/app/controllers/integrationsController.js` nulls the token but never calls Google's revoke endpoint (TASKS BE-022); the copy on the P9 row
