### CMP-043 · Disconnecting YouTube in the app revokes access at Google
- kind: OBLIGATION
- rule: When the user disconnects YouTube in Kokonada, the backend revokes the token with Google straight away, and all YouTube data it collected is deleted within 7 calendar days.
- source: YouTube API Developer Policies III.D.2, item 3.1: "When a user revokes consent through this mechanism, the API Client must programmatically revoke that token right away to communicate the change in permissions to Google… That deletion should happen as soon as possible and must take place within 7 calendar days of the revocation." https://developers.google.com/youtube/terms/developer-policies · retrieved 2026-09-29
- provider: YouTube
- applies to: P9, backend
- surfaces: the YouTube disconnect handler in `backend/app/controllers/integrationsController.js` nulls the token but never calls Google's revoke endpoint (TASKS BE-022); the copy on the P9 row
- verify at: Under DEC-122 (YouTube connect sealed in code): CI — `youtubeSeal.test.js` (both constants false, no env read), `youtubeSeal.integration.test.js` (connect and callback refuse with `youtube_unavailable` and never store a token), `youtubeTokenWriters.structural.test.js` (the only writers of `youtubeMusicToken` are the sealed callback and the refresh), and the disconnect no-op tests (no path drops a stored YouTube grant without revoking it: 409 `youtube_link_present`). Production — DAN-046 P0, P0b and P1 show no `youtubeMusicToken` holder and no unaccounted past grant, and P2 shows the sealed refusal. If `YOUTUBE_CONNECT_ENABLED` is ever set true, this entry reopens as HALT with "CI — a test checks the revoke call (refresh token, form body) and the deletion job. G12 — a disconnect capture" (ARCH-012: M7–M11 first). · Amended 2026-10-02: P0b now has positive evidence of a past YouTube link: the production Redis job payloads hold YouTube entries at library scale from 2026-07-06, which suggests a YouTube library import (TASKS `OPS-094`, `DAN-046`), so at least one account probably linked YouTube, and the old disconnect deleted the token without revoking it (`BE-022`). The entry stays HALT: the grant holder removes the grant at Google and the date is recorded. The Railway logs start 2026-09-29 and cannot cover July, so P0b rests on the Google Cloud console.
