### CMP-019 · No Spotify content goes into ML or AI models
- kind: PROHIBITION
- rule: No Spotify content (track IDs, metadata, genres, cover art) trains or is fed into any ML or AI model, and that includes LLM prompts and the learning agents. Learning stays provider-neutral.
- source: Spotify Developer Policy III.14: "Do not use the Spotify Platform or any Spotify Content to train a machine learning or AI model or otherwise ingest Spotify Content into a machine learning or AI model." Spotify Developer Terms IV.2.a.i (same wording). https://developer.spotify.com/policy ; https://developer.spotify.com/terms · retrieved 2026-09-29
- provider: Spotify
- applies to: backend, server plumbing, P3, P4
- surfaces: `backend/app/models/RewardEvent.js:12-18`: under ADR-0012, track A is provider-neutral and track B accepts only CC0 `mbid:` keys, enforced by schema hooks. The LLM prompt builder leaves out Spotify-derived genres. The captions of TASKS BE-044.
- verify at: CI — the ADR-0012 hook tests, plus a test that no `spotify:` ID or Spotify metadata reaches any prompt
- severity if broken: P0
- depends on: none
- status: SETTLED
- re-verify by: 2026-11-28
