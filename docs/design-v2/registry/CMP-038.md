### CMP-038 · Call it "YouTube", never "YouTube Music"
- kind: OBLIGATION
- rule: The integration is labelled "YouTube" wherever it appears. The app reads the YouTube Data API (`youtube.readonly`), and "YouTube Music" is a separate Google product name that the API branding does not cover.
- source: YouTube API Developer Policies III.F.2.a: "Any API Client page or feature that displays YouTube content must make clear to the viewer that YouTube is the source … by displaying YouTube Brand Features in accordance with requirements and the YouTube Branding Guidelines". YouTube Branding Guidelines ("you may reference the fact that your app is for YouTube or works with YouTube…"; they never mention YouTube Music). https://developers.google.com/youtube/terms/developer-policies ; https://developers.google.com/youtube/terms/branding-guidelines · retrieved 2026-09-29
- provider: YouTube
- applies to: P6, P9, P13
- surfaces: `mobile/KokonadaHealth/src/experience/connect/providers.ts:37` (`label: 'YouTube Music'`), shown in Connect and in `ProfileScreen.tsx:307`.
