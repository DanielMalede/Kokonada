### CMP-024 · Retention window for provider track data
- kind: OPEN QUESTION
- rule: The owner sets one retention window for provider-derived track data in History and events. The limits are: YouTube 30 days at most (CMP-045); Spotify never indefinitely, and 5 days after disconnect. My recommended default is 30 days for both; after that, History shows only Kokonada's own fields (time, mood, session title), which matches "re-tune from this moment".

- verify at: G1 — the P8 brief carries the window
- severity if broken: P0
