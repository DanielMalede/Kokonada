### CMP-057 · Derived results credit Garmin as a contributing source
- kind: OBLIGATION
- rule: When Garmin API data feeds a result (a mix, an inferred state, a Receipt), the result lists Garmin as a distinct or contributing source. Garmin's own acceptable wording: "Insights derived in part from Garmin device-sourced data." The line is its own text line that never truncates.
- source: Garmin Developer API Brand Guidelines V 6.30.2025, "COMBINED OR DERIVED DATA": "The attribution must list Garmin as a distinct or contributing data source (depending on what is true) and must not imply Garmin endorsement of data from other devices."
