### CMP-035 · Spotify authorisation only when the user asks
- kind: PROHIBITION
- rule: Spotify's authorise screen opens only when the user explicitly asks for Spotify. It never opens at boot, on automatic play or on reconnect, and never for an account that has not linked Spotify.
- source: Spotify Developer Policy, Section I "Respect users and data": "Only request and process the data that is needed to operate your SDA." https://developer.spotify.com/policy · retrieved 2026-09-29
- provider: Spotify
- applies to: P1, P3, P6, Q3
- surfaces: boot is fixed (PR #193 `playerBootGate.ts`). The play-time path is still open: `spotifyController.ts:131-145` → `spotifyRemoteAdapter.ts:43-58` (MB-040).
- verify at: CI — a stateful-fake test shows an automatic play never calls `SpotifyRemote.authorize`
- severity if broken: P1
- depends on: none
- status: SETTLED
- re-verify by: 2026-11-28
