### CMP-118 · Reserved Font Names on modified fonts
- kind: PROHIBITION
- rule: A font that has been subset, converted or instanced is a Modified Version, and its name must not contain a Reserved Font Name. The reserved names are "Plex" (IBM Plex Sans, IBM Plex Sans Hebrew), "Source" (Assistant) and "Hadash", "Gentium", "SIL" (David Libre). Either ship the upstream files byte-identical, or rename.
- source: OFL 1.1, condition 3: "No Modified Version of the Font Software may use the Reserved Font Name(s) unless explicit written permission is granted by the corresponding Copyright Holder." OFL FAQ (subsetting and conversion count as modification). Reserved names as declared in the OFL.txt files at google/fonts: `ofl/ibmplexsans`, `ofl/ibmplexsanshebrew`, `ofl/assistant`, `ofl/davidlibre` (https://github.com/google/fonts/tree/main/ofl) · retrieved 2026-09-29
- provider: OFL font
