### CMP-090 · A report control on any text an LLM wrote
- kind: OBLIGATION
- rule: Any text an LLM wrote that the app shows (Now Playing captions, Receipt prose) carries an in-app control to report or flag it. Otherwise that text never renders in a Play build.
- source: Google Play Developer Policy, generative-AI content policy: "Apps that generate content using AI must contain in-app user reporting or flagging features that allow users to report or flag offensive content to developers without needing to exit the app." https://support.google.com/googleplay/android-developer/answer/13985936 · retrieved 2026-09-29
- provider: Google Play
- applies to: P3, P4, server plumbing, store listing
- surfaces: `NowPlayingScreen.tsx:119,249-256` shows the caption with no report control; the `DISCOVERY_CAPTION_LLM` flag's production value is unread (BE-044, DAN-018)
- verify at: store submission. G12.
- severity if broken: P0
- depends on: none
- status: SETTLED
- re-verify by: 2026-11-28
