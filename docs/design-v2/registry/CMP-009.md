### CMP-009 · Spotify link-back wording
- kind: OBLIGATION
- rule: If Spotify is installed, the link reads "OPEN SPOTIFY", "PLAY ON SPOTIFY" or "LISTEN ON SPOTIFY". If it is not installed, it reads "GET SPOTIFY FREE".
- source: Spotify Design Guidelines: "If the Spotify app is not installed then the link should say, GET SPOTIFY FREE. If the Spotify app is installed then use any of the following text strings: OPEN SPOTIFY, PLAY ON SPOTIFY or LISTEN ON SPOTIFY". https://developer.spotify.com/documentation/design · retrieved 2026-09-29
