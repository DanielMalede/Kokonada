### REG-033 · Read only the user's own wearable
- kind: OBLIGATION
- rule: No heart rate is read from a device the user has not picked or confirmed as theirs.
  - Today the scan connects to the first heart-rate broadcaster in range (`mobile/KokonadaHealth/src/health/bleHeartRate.ts:45-53`; MB-020). That can read a stranger's health data with no lawful basis.
