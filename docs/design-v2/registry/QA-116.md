### QA-116 · Every pinned production function has a production caller
- kind: OBLIGATION
- rule: A test that pins a production export requires ≥1 non-test caller, unless the export is on the dead list scheduled for removal.
- check: MISSING. Live cases: `auth.signOut` pinned by `mobile/KokonadaHealth/src/auth/__tests__/loginFlow.test.ts:141-155` with no production caller (MB-018); `advancePulsePhase`; `startPlayback` (held uncalled on purpose, `shadow.healthLane.test.ts:193-195`).
- applies to: Q1; P1–P14
- verify at: G10, CI
- pass rule: 0 pinned exports without a caller outside the dead list.
- severity if broken: P1
- depends on: none
- status: MISSING · Amended 2026-11-22: MISSING — in part. Built at `7432c81` (#292) and run on every PR in CI's Mobile jest job (green at `7432c81`). The check runs in-process on QA-043's loader (`src/testing/guards/pinnedCallers.ts`). A pin is a callable or constructable production export that a test names through a value import (named, default or namespace), `require('<literal>').name`, `jest.requireActual('<literal>').name` or `const { name } = require('<literal>')`, followed through barrels and renamed re-exports to its declaration. A caller is a value-position reference from a production file that the release entry (`index.js`, `App.tsx`) reaches; the Design Lab, orphan modules and `src/__contracts__` do not count. It is pinned by `src/testing/__tests__/pinnedCallers.test.ts`, whose planted controls each failed first. The pass rule holds on the real tree: 212 pinned exports, 0 without a caller outside the dead list (`src/__contracts__/deadList.ts`, 13 entries against a ceiling of 13, each citing an open row that names it), and the program's test files equal those on disk (`src/__contracts__/__tests__/pinnedCallers.test.ts`). `startPlayback` is outside the rule: no test imports it, `shadow.healthLane.test.ts:193-195` holds it uncalled by a text scan, and its removal is `OPS-024`. Owed: the v2 field clock that only the Design Lab calls (`OPS-437`); pins through a `src/testing` helper or a bound `require()`, and type-only edges in the release closure (`OPS-438`); the overlay's directory gap (`OPS-436`); `src/__contracts__` as a scoped tsc root (`OPS-428`); the nested `ios`/`android`/`build` skip in `walkSources` (`OPS-439`). Audit of #292, round 2 (`resilience-auditor`).
