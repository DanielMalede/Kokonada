### CMP-034 · No automated Spotify plays
- kind: PROHIBITION
- rule: Spotify starts only from a user action, or from a live mode the user switched on while present. Nothing plays after the session ends or while the user is gone.
- source: Spotify Developer Policy II.2: "Don't artificially increase, or claim to artificially increase, play counts, follow counts or otherwise manipulate the Spotify Service. This includes: (i) using any bot, script or automated process…" https://developer.spotify.com/policy · retrieved 2026-09-29
- provider: Spotify
- applies to: P2, P3, Q3
- surfaces: auto-continue at the end of the queue, Live playlists pushed from the server, reconnect re-sends (MB-040)
- verify at: CI — a stateful-fake test shows that with no user session, nothing plays
- severity if broken: P1
- depends on: CMP-035
- status: SETTLED
- re-verify by: 2026-11-28
