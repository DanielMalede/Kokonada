### CMP-014 · Spotify metadata as provided, and always readable in full
- kind: OBLIGATION
- rule: Track, artist, album and playlist names appear exactly as Spotify returns them and stay legible. They may be truncated only if the user can still see the whole string.
- source: Spotify Design Guidelines: "Track, artist, playlist, and album titles must always be presented with the metadata provided by Spotify." "The metadata must always be legible." "You may truncate metadata if space is limited. The user should always be able to view the entire metadata." Also Policy II.3. https://developer.spotify.com/documentation/design · retrieved 2026-09-29
- provider: Spotify
- applies to: P3, P4, P8
- surfaces: `NowPlayingScreen.tsx:185` (title, 2 lines) and `:191` (artist, 1 line), and `UpNextRow.tsx:66,71` truncate with no way to see the full name (MB-043). Title and artist come from Kokonada's queue while the cover comes from App Remote (`nowPlayingStore.ts`), so the two can disagree.
- verify at: G12 — a long-title fixture at font 2.0 shows the full string on the device
- severity if broken: P1
- depends on: none
- status: SETTLED
- re-verify by: 2026-11-28
