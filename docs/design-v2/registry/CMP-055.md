### CMP-055 · Garmin attribution on secondary and history views
- kind: OBLIGATION
- rule: Detail, report, settings and history views that show Garmin data carry the attribution. On lists it can go in a shared header or on each entry. Screenshots must keep it.
- source: Garmin Developer API Brand Guidelines V 6.30.2025, "SECONDARY SCREENS" (txt:45-47, 50-52: "For multi-entry displays, you can apply the attribution globally — such as in a header — or per entry. Screenshots, printouts and reports must retain visible Garmin attribution.") · retrieved 2026-09-29

- surfaces: Pulse detail views, History rows
