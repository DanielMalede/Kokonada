### CMP-116 · System splash-screen rules
- kind: OBLIGATION
- rule: Use the system SplashScreen. The icon is 240 dp inside a 160-dp circle with a background, or 288 dp inside a 192-dp circle without one. Animation lasts 1,000 ms at most, and there is no second splash (the JS breath continues seamlessly).
- source: Android splash screen (updated 2026-09-22): "App icon with an icon background: this must be 240×240 dp and fit within a circle 160 dp in diameter. App icon without an icon background: this must be 288×288 dp and fit within a circle 192 dp in diameter"; "we recommend not exceeding 1,000 ms on phones". https://developer.android.com/develop/ui/views/launch/splash-screen · retrieved 2026-09-29
- provider: Android
- applies to: P12
- surfaces: `bootsplash`, `MainActivity.kt`, `styles.xml`
