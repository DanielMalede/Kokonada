### CMP-102 · OAuth never runs in an embedded WebView
- kind: PROHIBITION
- rule: Google sign-in uses the native SDK. YouTube, Spotify and Garmin authorisation run in the system browser or a Custom Tab and return through `kokonada://integrations`. None runs in an in-app WebView.
- source: Google OAuth 2.0 Policies (updated 2026-08-05): "A developer must not direct a Google OAuth 2.0 authorization request to an embedded user-agent under the developer's control." https://developers.google.com/identity/protocols/oauth2/policies · retrieved 2026-09-29
- provider: Google OAuth
- applies to: P1 (deep link), P6, P11
- surfaces: the only WebView is `PermissionsRationaleActivity`; the `kokonada://integrations` filter at `AndroidManifest.xml:68-73`
- verify at: G12 — plus `/security-review` on P6 and P11
- severity if broken: P0
- depends on: none
- status: SETTLED
- re-verify by: 2026-11-28
