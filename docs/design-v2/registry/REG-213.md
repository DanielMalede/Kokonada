### REG-213 · UK: an inferred state is shown as uncertain and drives no decision
- kind: OBLIGATION
- rule: Wherever an inferred state is shown or stored, it is presented as uncertain and correctable. No inferred state drives any decision about the user other than which music is played.
- source:
  - UK GDPR Art. 5(1)(a): "lawfully, fairly and in a transparent manner".
