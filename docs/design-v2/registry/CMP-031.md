### CMP-031 · No broadcasting one stream to many listeners
- kind: PROHIBITION
- rule: Live mode serves exactly one listener. There are no group, party or shared sessions.
- source: Spotify Developer Policy III.4: "Do not create any product or service which includes any non-interactive internet webcasting service. For example, you can't create an application which plays content from a single source to several simultaneous listeners." https://developer.spotify.com/policy · retrieved 2026-09-29
- provider: Spotify
- applies to: P2, P3
- surfaces: `live_mode`; any future sharing feature
- verify at: G1 — the charter lists no multi-listener path
- severity if broken: P1
- depends on: none
- status: SETTLED
- re-verify by: 2026-11-28
