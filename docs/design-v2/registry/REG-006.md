### REG-006 · Notice no later than first exposure, per person
- kind: OBLIGATION
- rule: The notice appears "at the latest at the time of the first interaction or exposure" for each person. That includes a new account on a phone that has already finished onboarding, so a per-device onboarding flag (`onboardingStore.ts:8-14`) cannot be what carries it.
- source: AI Act Art. 50(5) [K1] · retrieved 2026-09-29 (REPRODUCTION). Art. 50 Guidelines point 143 [K4] (COMMENTARY: "First exposure applies to each output and each person…")
- jurisdiction: EU
- classification assumption: only if ER-Y; the owner ships it under every option
- applies to: P2, P6, P10, P11; Stage 0 F10
- surfaces: Generate first frame; Onboarding chrome
- verify at: G12 — a capture of a second account on an already-onboarded phone shows the notice before any inferred output
- severity if broken: P0
- depends on: REG-005, REG-007
