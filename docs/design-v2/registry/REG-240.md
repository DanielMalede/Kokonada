### REG-240 · California: request the age signal (operative 1 January 2027)
- kind: OBLIGATION
- rule: From 1 January 2027, Kokonada requests the OS or app-store age signal when the app is downloaded and launched, and treats the range it receives as actual knowledge.
- source: California AB 1043 (Ch. 675, approved 13 Oct 2025), new Civ. Code §1798.501. https://leginfo.legislature.ca.gov/faces/billTextClient.xhtml?bill_id=202520260AB1043. retrieved 2026-09-29 [RETRIEVED]. It says:
  - "A developer shall request a signal with respect to a particular user from an operating system provider or a covered application store when the application is downloaded and launched";
  - "…shall be deemed to have actual knowledge of the age range of the user";
  - "This title shall become operative on January 1, 2027".
- jurisdiction: US-CA
- classification assumption: launch is around 2027 (ADR-0016) and California users are included.
- applies to: P10, backend
- surfaces: the age slot
