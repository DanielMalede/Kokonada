UNFILLED — DELIBERATELY

There is no error component. This board records the hole rather than inventing a spec for it: an honest gap gets chased, an invented one gets built. Until it exists, every screen’s error path is whatever that screen improvised.

When it is specified it should mirror EmptyState exactly — title, a one-sentence body naming what failed, and a required retry action, so a dead-end error is unrepresentable too. Tone danger, never the emotion accent: a fault is not a mood.

COVERAGE TODAY

Error is owed on eleven screens and drawn on none — the same finding as the missing component, reached from the other end. Skeleton is drawn on three of the four screens that actually wait on a request.
