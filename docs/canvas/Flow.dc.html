How the magic moment moves

Five transitions carry the whole product. Until now nothing in the design said how any of them behaved — so each was going to be invented at build time, differently, three times. Every value below is a token from tokens.ts, and every one has a designed still for reduced motion.

TRANSITION 00 The read lands 1200 MS · EASE/CALM · 80 MS STAGGER

This happens on Generate, before Transition 01. You place how it feels and the dots take the hue of that emotion. Then the body read resolves — and if the body disagrees, the dots move to the fused state in front of you. They warm or cool depending on the fusion — neither direction is the rule. It is the app saying I heard you, and here is what is actually happening. It is a moment, not a repaint: never instant, never a flicker, and it happens once.

HOW IT BEHAVES
It waits for the body, not the tap. The dots hold the placed hue until the read resolves — about 300 ms. Moving before the answer exists would be theatre.
1200 ms on ease/calm, the same duration as a field state change, because it is the same event seen from a different element. Token: motion.duration.settle = 1200 — one name for the duration this and Transition 03 share.
80 ms stagger, newest dot first. The three cool as a wave rather than a switch, so it reads as something arriving rather than a value being overwritten.
The halo and the hull follow the dot; the field, the CTA and the confidence fill cross-fade on the same curve. One event, every accent-bearing element, one duration.
It happens once per read. A second placement that does not change the fused quadrant does not re-run it. Nothing about a calm screen should blink.
No haptic. selection already fired when the dot landed. Buzzing again on the app's own answer would make the verdict feel like an alert.
Reduced motion: the dots render at the fused hue from the moment the read resolves. No cross-fade, no stagger — the amber frame is never shown, because a still of a transition is a lie about what happened. The read card appears without its fade.

WHAT CARRIES ACROSS THE CUT
The placements are the shared element. All three converge on the plate's centre and become the filled inner ring. They do not fade out and get replaced — the same objects move, so the user's marks visibly become the thing that is thinking.
The field does not reset. Hue and reach hold exactly as they were. Crossing this cut must never feel like arriving in a different body.
Everything else leaves first. Chips, prompt and CTA fade over motion.duration.fast (120 ms) so the plate is alone before it transforms.
Haptic: commit fires once, on touch-up, before the animation — not on arrival.
Reduced motion: the placements cross-fade to the ring over 120 ms in place. No convergence, no scale. Identical layout, identical copy.

WHAT CARRIES ACROSS THE CUT
The filled inner ring is the album art. One shared element, morphing border-radius 50% → radius.md while it grows and rises. The thing that was thinking becomes the thing that is playing; nothing is created or destroyed at the cut.
The status line becomes the track title. Same position, cross-faded over the last 140 ms as it rises 22 px.
The field settles, slowly. Nothing about the field happens at this cut, because Now Playing has no living field. NowPlayingScreen.tsx renders no LivingAurora, no AuroraGradientFill and no BioAura — its only ambient element is the PlaybackAura behind the art, and that is accent.glow: the FIXED brand accent, never the emotion. The canvas draws a field here that the app does not have. Until that is resolved this transition claims nothing about hue — and if the field is ever extended to this screen, it moves under Transition 03’s rule (two consecutive reads), never on arrival.
Haptic: success fires when audio actually starts — never when the request is sent.
Reduced motion: cross-fade only, 160 ms, art already at its final size and radius. The field still re-tints — it is a state change, not an animation — but it steps rather than eases.
TRANSITION 03 The field changes state 1200 MS · EASE/CALM
Hue and reach cross-fade together over 1200 ms. Two field layers are alive during the change; the outgoing one fades as the incoming one rises, so there is never a flat frame.
The period only ever retimes at a cycle boundary. If the breath is mid-inhale when the state changes, the new period takes effect at the next zero-crossing. Retiming mid-breath produces a visible stutter — and a stutter in the one element whose whole job is to be calm is worse than being 4 seconds late.
It is never triggered by a single reading. The state must hold for two consecutive reads before the field moves. A field that flickered between states on sensor noise would be exhausting.
Reduced motion: hue and reach step to their new values in one frame. No cross-fade, no easing.
TRANSITION 04
The two pushed screens
240 MS · EASE/CALM · MOTION.DURATION.BASE

Neither the Mix receipt nor the Health Data Vault is a tab. Both are pushed and both are dismissed, and until now this board said nothing about either — which is how one screen ends up sliding, one fading and one doing whatever the navigator does by default.

NOW PLAYING → MIX RECEIPT
The receipt sentence is the shared element. It is already on Now Playing as one line; on push it rises into the verdict head and grows to 21px. The user’s own summary becomes the argument’s title — nothing is created at the cut.
The art stays put. It does not travel and it does not fade; the receipt covers it. Returning uncovers the same object in the same place, so the set never feels interrupted.
Playback is untouched. No pause, no duck, no haptic. Reading why a track was chosen is not an interaction with the track.
PROFILE → HEALTH DATA VAULT
No shared element, deliberately. This is a detour, not a continuation. Nothing from Profile travels, because implying continuity would soften a screen whose job is to be plain.
The tab bar leaves on the push and returns on dismiss. While the Vault is open there is exactly one way out, and it is the back affordance. A tab bar here would offer four ways to leave a decision half-made.
The field is still. No breath, no drift, for as long as the Vault is open. The one screen about switching the reading off should not be visibly reading.
REDUCED MOTION Both open and close as a 0 ms cut, with the field unchanged across it. A pushed screen that slides is decoration; a pushed screen that appears is navigation.
THE DEGRADATION LADDER

The order is the design. The condition is what makes it implementable — without one named per rung the thresholds get invented at build time, which is the failure this board exists to prevent. Reduced motion is not a rung. It is a separate, complete still that applies at any rung, and it is the only one of these signals the app can read today: AccessibilityInfo.isReduceMotionEnabled(), via useMotion().

ONE BREATH, FOUR APPEARANCES
The splash mark
One cycle while the session restores, then it hands off at the top of the inhale.
The live dot
At the end of the six-minute trace, on Generate and Pulse. The only thing on either screen that moves.
The field
Two lobes at T and 1.35 T, where T is the regulation target.
The Genesis rings
Three, on 380 ms phase offsets, so the group reads as one organism rather than three circles.

All four are the same curve — motion.duration.breath at 4200 ms, opacity .45 → .75, scale 1 → 1.04, nothing else. No blur, no position, no colour. Phase advances by elapsed time, never by frame count, so it is identical at 60 and at 120 Hz and it does not lurch when a frame is dropped. Only one loop runs at a time on any screen.
