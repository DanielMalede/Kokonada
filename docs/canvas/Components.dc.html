The four bar grammarsHEIGHT 8 · RADIUS.PILL · TRACK AT 3:1

A ceiling is an exclusion. A target is a point. A bias is a signed nudge. A stack is a composition. The canvas was drawing all four as one left-anchored fill, which made "tempo ceiling 96" read as an achievement and put four bars on Pulse where fuller meant better for three of them and worse for the fourth. Every one of these carries its unit and its direction in words.

THE RULE THAT DECIDES

If the number is a limit, it is a ceiling. If it is a value we aim at, it is a target. If it can be negative, it is a bias. If the parts add up to a stated whole, it is a stack. Nothing on Pulse or the receipt may use a bar that does not answer to one of these four — and on Pulse, further right must always mean more of the thing named, so resting heart rate is inverted and says so in words.

Two system rules, ratified from screen work DANIEL · 2026-08-26 · REVISITABLE

Both of these were first made locally, to fix one screen. They are recorded here as the system answer so they are applied once rather than patched per board. Neither is locked: if this board later shows a better answer for either, it changes here, once, and propagates.

Controls take --brand, never the field accent RULE 1

A switch, a slider and their tracks are chrome: they mean the same thing whatever the user is feeling. Painting them with the reactive accent made them change colour with the fused state, and on a fieldless screen it resolved to the reflective ink — the undeclared blue that appeared on Onboarding, Connect, Now Playing and Profile. The fixed brand accent is declared, stable, and clears the 3:1 non-text floor in both faces.

Track derives from the same hue as its fill. Target ≥ 44 regardless of the drawn pill.
Tab-bar chrome is neutral ink RULE 2

The active tab used --accent. On a one-state screen that reads fine, because the accent is the screen. On the archive — which shows four quadrant colours at once — “this tab is selected” was painted the same colour as the reflective rows, so selection and state became the same signal. Chrome must never borrow a quadrant.
