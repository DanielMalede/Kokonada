Ship the current task per docs/ORCHESTRATOR_FABLE.md <pr_workflow>. ultrathink.
Full-suite gate (backend `npm test`; mobile jest local + `npm run lint:design-system`) → commit (short single-line, no body/trailers, NO AI attribution) → push branch → `node scripts/coord/coord.js ship` in the task worktree (moves the ledger slot to `in-review · PR #N` and pushes; it reports drift between declared and changed files: `rescope` any file that really belongs to the task, and a HALT there stops the ship) → `gh pr edit --body-file` on the draft PR opened at claim time (a branch with no claim falls back to `gh pr create --body-file --draft`, only after `coord check` on its changed files is CLEAR) → run the `resilience-auditor` in OWN TREE on this worktree at the pushed head H, with the diff, the acceptance criteria and H, never the reasoning that wrote the code; post its report as a PR comment (`gh pr comment N --body-file`, UTF-8, LF); every finding becomes a `TASKS.md` row at once → `gh pr ready` only on `VERDICT: APPROVE @ H`; `VERDICT: BLOCK @ H` = task FAILED: fix in-branch (add every PROPOSED TEST), push, and run the auditor again on the new head before `ready` → confirm CI green on the head → STOP and await my explicit merge approval. Never self-merge. Any red gate = task FAILED; report and stop. A design-v2 page ships only through /page; this command never stands in for G10–G12.
